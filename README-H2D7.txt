BOUNTY TRACKING
- Each player starts every new Bounty at 10% chance to find the actual target.
- Every Bounty Hunt produces an encounter.
- If the target roll fails, a normal monster appears on the Bounty Trail.
- Player must catch that monster with the normal capture system.
- Successful decoy catch = new clue + personal target chance rises +10%.
- Progression: 10% > 20% > 30% > 40% > 50% > 60% > 70% cap.
- Failed decoy catch = no clue and no tracking increase.
- When actual target appears, player still must catch it normally.
- All personal tracking resets to 10% when the next Bounty starts.
- Activity shows personal Target Chance + Clues Found.

HUNT TOKENS
Every successful catch now awards Hunt Tokens using the existing rarity values:
Common 1
Rare 2
Epic 4
Legendary 8
Mythic 15
Bounty/other fallback 1

During Big Game Hunt these payouts are DOUBLED:
Common 2
Rare 4
Epic 8
Legendary 16
Mythic 30

Existing Token Rush / Token Surge bonuses remain additive.
Big Game leaderboard score uses the doubled tokens actually earned.
